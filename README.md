#🍪 Solycarve 3D — Gerador Avançado de Cortadores de Biscoito

Solycarve 3D é uma aplicação web interativa desenvolvida com Three.js e Tailwind CSS que permite converter qualquer foto, logo ou silhueta em um modelo tridimensional de alta precisão, totalmente otimizado para impressão 3D de cortadores de biscoito em PLA ou PETG.

✨ Principais Funcionalidades

Upload de Imagem Inteligente: Envie fotos, desenhos ou silhuetas para gerar a malha tridimensional do cortador instantaneamente.

Visualização 3D em Tempo Real: Renderização tridimensional interativa com rotação suave, iluminação dinâmica e sombreamento profissional.

Parâmetros Avançados de Impressão 3D:

🎚️ Altura da Lâmina: Ajuste milimétrico para cortar massas espessas.

🧱 Espessura da Parede: Garante resistência mecânica sem deformações.

📏 Escala e Tamanho: Redimensione o cortador milimetricamente.

📐 Borda de Apoio (Pega): Área ergonômica para manuseio.

✨ Chanfro (Bevel): Otimiza o corte limpo da massa.

Exportação STL: Baixe o arquivo pronto para fatiar no seu software de impressão 3D (Cura, PrusaSlicer, etc.).

🚀 Como Executar o Projeto

Clone o repositório:

git clone 

Abra a pasta do projeto.

Abra o arquivo index.html em qualquer navegador moderno.

⚙️ Tecnologias Utilizadas

Three.js (r128): Computação gráfica e renderização 3D na web.

Tailwind CSS: Interface moderna baseada em componentes Glassmorphism.

JavaScript (ES6+): Algoritmos de extrusão paramétrica vetorial.

🖨️ Configurações Recomendadas para Impressão 3D

Material: PLA ou PETG (Grau alimentício recomendado).

Preenchimento (Infill): 15% a 20% (Padrão Grid / Gyroid).

Altura de Camada: 0.2 mm.

Pós-processamento: Higienizar a peça com água morna e sabão neutro antes do contato com alimentos.
